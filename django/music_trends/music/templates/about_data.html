About the Data

Data sources, RDF schema, and setup instructions.

Data Sources

The dataset combines multiple Kaggle sources:

  • hot100.csv — Billboard Hot 100 chart history
  • global200.csv — Spotify Global 200 streaming chart
  • spotify-tracks-dataset-detailed.csv — Spotify audio features
  • radio.csv — Radio chart data
  • digital.csv — Digital sales chart

RDF Schema

Namespaces:

PREFIX pred: <http://music.org/pred/>
PREFIX type: <http://music.org/type/>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

Classes:  type:Song  type:Artist  type:ChartEntry

Setup Instructions

  1. Create a virtual environment & install dependencies
    python3 -m venv .venv && source .venv/bin/activate
    pip install -r django/music_trends/requirements.txt
  2. Generate the RDF file
    python normalizing_data/create_rdf.py
  3. Import music.ttl into GraphDB
    Use the GraphDB Workbench (Import → RDF Files) or the REST API. Target repository: music.
  4. Start the Django server
    cd django/music_trends && python manage.py runserver
  5. Open in browser
    http://127.0.0.1:8000/
